BEASSI ARQUITETURA — VERSÃO 10 | PREPARAÇÃO PARA INTEGRAÇÃO DINÂMICA

O QUE FOI PREPARADO
- Criada a camada central Js/api.js para chamadas HTTP ao Spring Boot.
- Criado Js/integracao_dinamica.js para conectar formulários e telas aos endpoints REST definidos no documento INTEGRACAO_DINAMICA_E_CONTRATO_API.md.
- Cadastro e edição de projetos: seleção dinâmica de clientes ativos, opção Nenhum cliente (clienteId = null), classificações residenciais/comerciais e categorias carregadas da API.
- Cadastro e edição de projeto enviam cliente, tipo/classificação, categorias, etapa e imagem para a API.
- Portfólio público, listagem administrativa de projetos, detalhe de projeto e área do cliente passam a carregar projetos pela API.
- Gerenciamento de clientes, detalhes/edição do cliente e situação ativo/inativo passam a consultar/atualizar a API.
- Formulários de login, cadastro, edição de perfil, feedback e recuperação de senha ligados aos endpoints definidos.
- Moderação administrativa de feedbacks ligada à API; o site público solicita apenas feedbacks aprovados.
- Removidos dados fictícios de várias listagens e a persistência de demonstração do progresso via localStorage.

IMPORTANTE
Este pacote contém o Front-End. O Back-End Spring Boot não estava incluído no ZIP recebido. Portanto, os endpoints descritos são o contrato esperado para integração, ainda precisam existir no Spring Boot e ser alinhados aos DTOs/Stored Procedures reais.

CONFIGURAÇÃO
Em Js/api.js, ajuste BEASSI_API_BASE_URL para a URL do Spring Boot. O padrão é http://localhost:8080/api.
